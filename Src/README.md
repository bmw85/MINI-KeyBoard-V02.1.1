# MINI KeyBoard

Windows-приложение для программирования дешёвых USB mini keyboard / macro pad (AliExpress и аналоги).

Тёмная минималистичная оболочка, интерфейс на русском, профили, запуск приложений с клавиш и работа из системного трея.

> Основано на декомпилированном китайском ПО (HIDTester). Код переработан для удобства и совместимости. Лицензия — [MIT](LICENSE).

---

## Совместимые устройства

| Параметр | Значение |
|----------|----------|
| **VID** | `0x1189` (4489) |
| **PID** | `0x8890` (34960) |
| **Клавиши** | 3–16 |
| **Энкодеры** | 0–3 (влево / центр / вправо) |

Типичные модели:

- 3 клавиши + 1 энкодер  
- 6 клавиш  
- 9 клавиш + 1 энкодер  
- 12 клавиш + 2 энкодера  
- 16 клавиш + 3 энкодера  

Устройства продаются под разными названиями, но используют один и тот же HID-протокол.

## Возможности

### Программирование клавиш

| Раздел | Что можно назначить |
|--------|---------------------|
| **Клавиши** | A–Z, цифры, символы, F1–F12, Esc, Tab, Enter, Backspace, стрелки, Home / End / PgUp / PgDn, Insert / Delete, NumPad и др. |
| **Ctrl Shift Alt** | Модификаторы Ctrl / Shift / Alt / Win и их сочетания, Shift+символы |
| **Мультимедиа** | Play/Pause, громкость ±, следующий / предыдущий трек, Mute |
| **Мышь** | ЛКМ / ПКМ / СКМ, колесо ±, Ctrl/Shift/Alt + колесо |
| **LED** | Выключение, готовые режимы подсветки, свой код режима (0–255) |
| **Приложение** | Запуск любого `.exe` с выбранной физической клавиши |

На главном окне:

- выбор **KEY1…KEY16** и позиций энкодеров **K1–K3**
- кнопки **Записать** и **Очистить**
- статус **Подключено** / **Не подключено**
- отображение текущего назначения клавиши

### Профили

На устройстве доступны **3 профиля** (слоя). Назначение записывается в **активный** профиль. Переключение профиля — в панели справа («Профиль 1 / 2 / 3»).

### Запуск приложений

Клавиатура **не хранит путь к программе**. Вместо этого:

1. Вы выбираете KEY и файл `.exe`
2. На устройство пишется комбинация **Ctrl+Alt+Shift+F1…F12**
3. Приложение слушает эти хоткеи и запускает нужный файл

Маппинг хранится в:

```text
%AppData%\MINI KeyBoard\app_launches.json
```

**Важно:** чтобы запуск работал, `MINI KeyBoard.exe` должен быть запущен (можно свернуть в трей).

### Системный трей

- **Крестик / Alt+F4 / сворачивание** — программа уходит в трей, горячие клавиши остаются активны  
- **Полный выход** — ПКМ по иконке → **Выход**  
- **Открыть окно** — двойной клик или ПКМ → **Открыть**

### Интерфейс

- тёмная минималистичная тема  
- русский UI  
- индикатор текущего профиля

## Что добавлено поверх оригинала

Оригинальное китайское ПО умело писать обычные клавиши, мультимедиа, мышь, LED и слои.

В этой версии дополнительно:

| Функция | Описание |
|---------|----------|
| **Открытие приложений** | Панель «Приложение» + запись на KEY + слушатель хоткеев |
| **Трей** | Сворачивание при закрытии, выход только из трея |
| **Русский интерфейс** | Перевод меню и основных панелей |
| **Тёмная тема** | Единый стиль (`UiTheme`) |
| **Профили в UI** | Понятные «Профили» вместо «Layer» |
| **Расширенный LED** | Доп. режимы и произвольный код 0–255 |
| **Устойчивый запуск** | Ошибки старта пишутся на рабочий стол (`MINI-KeyBoard-error.txt`) |
| **Исправленный layout** | Абсолютная раскладка KEY/кнопок без наложений |

Обычные макросы (клавиши, медиа, мышь) **живут в прошивке** и работают без этого exe.  
Запуск приложений — **только пока программа открыта** (в т.ч. в трее).

## Ограничения прошивки

- Обычно **до 5 символов** на одну клавишу (лимит устройства)
- Модификаторы (Ctrl / Shift / Alt) занимают слоты вместе с символами  
  Пример: `Shift` + несколько букв быстро «съедает» лимит
- Автозапуска с Windows в программе пока нет — при необходимости добавьте ярлык в автозагрузку вручную

## Быстрый старт

1. Подключите клавиатуру по USB  
2. Запустите `MINI KeyBoard.exe`  
3. Дождитесь статуса **Подключено**  
4. Нажмите нужную кнопку **KEY** (или позицию энкодера)  
5. Выберите действие в левом меню  
6. Нажмите **Записать**

### Открыть приложение с клавиши

1. Выберите **KEY1…KEY16**  
2. Меню **Приложение** → укажите `.exe`  
3. Нажмите **Записать на клавишу**  
4. Оставьте программу в трее

## Сборка из исходников

Стек: **C# / WinForms / .NET Framework 4.8**

Из папки `Src`:

```bash
msbuild "MINI KeyBoard.sln" /t:Restore /p:Configuration=Release
msbuild "MINI KeyBoard.sln" /p:Configuration=Release /p:Platform="Any CPU"
```

Готовый файл появится в `Src\bin\Release\`. Для репозитория готовая сборка лежит в папке **`Replace/`** в корне.

---

## Протокол (кратко)

Устройство принимает USB HID-отчёты (~65 байт):

- Report ID конфигурации: `0x03`
- позиция клавиши и тип действия
- данные назначения (символы / модификаторы / медиа / мышь / LED)

Запись идёт через HID (`HidLibrary` / WinAPI).
